# Ball Takes Product Model

Core loop:
Discover -> Follow pundits -> Predict -> Compare -> Result -> Receipt -> Banter -> Studio -> Export -> External AI/media tool -> Share -> Return.

The differentiator is not prediction alone. Ball Takes remembers what the user and pundits said, compares those takes with reality, discovers the interesting story, and packages the context for social-media creation.

Primary surfaces:
- Predict / Matchweek
- Banter
- Studio
- Leagues / Aura

Studio consumes context from:
- user predictions
- pundit predictions/takes
- results
- statistics
- news/RSS
- YouTube/transcripts
- league position
- Aura movement
- prediction history
