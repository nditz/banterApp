# Visual System

Personality: premium football editorial + creator product + group-chat banter.

Use:
- black/off-black shell
- off-white text
- Ball Takes green for selected/active/progress/Aura/primary CTA
- club colors only as local context
- strong numeric typography
- varied editorial feed cards
- subtle purposeful animation

Avoid:
- neon everywhere
- glowing borders
- heavy gradients
- glassmorphism
- over-rounded cards
- excessive borders
- identical card treatment across every content type
- random arbitrary spacing/radius values

The shell is clean. Content is lively.
