# UI, UX and Engagement Direction

## Brand direction

Preserve the BallTakes personality:

- black/green identity;
- bold football aesthetic;
- playful banter;
- "I know ball" energy;
- receipts;
- aura/knowledge concepts where useful.

Do not turn the product into a generic enterprise dashboard.

## Mobile first

Primary usage likely happens while watching football, using group chats and social media on a phone.

Core actions must require very few taps:

- predict;
- change prediction before lock;
- create banter;
- share/export.

Test at minimum around:

- 375px
- 390px
- 430px
- 768px
- 1024px
- 1440px

Avoid horizontal overflow and hover-only critical actions.

## Homepage direction

Suggested priority:

1. Hero: "Think you know ball? Prove it."
2. Current/next matchweek and prediction completion status.
3. User score/ranking.
4. You vs Pundits.
5. Upcoming fixtures.
6. Private leagues.
7. Pundit takes.
8. Latest receipts.
9. Premier League table snippet.
10. Football news/videos.
11. AI Content Studio CTA/latest generated banter.

The homepage should not become an undifferentiated news feed. News supports the prediction/banter loop.

## Match hub

Consider fixture pages as convergence points for:

- teams;
- kickoff;
- standings/form;
- user prediction;
- community prediction split;
- pundit predictions;
- related news/videos;
- result;
- receipt;
- generate banter action.

## Matchweek UX

Make matchweeks prominent:

- completion progress;
- predictions;
- points;
- accuracy;
- exact scores;
- global rank;
- private-league rank;
- performance vs pundits.

## Pundit UX

Create:

- pundit leaderboard;
- pundit profile pages;
- source/provenance links;
- "me vs pundits" cards;
- filters if they remain useful for a curated set.

## Feedback and animation

Use animation sparingly for meaningful state changes:

- prediction locked;
- points awarded;
- ranking movement;
- receipt unlocked;
- content generated.

## Feed integrations

Reuse existing RSS, YouTube and sports-data integrations where appropriate.

The feed should emphasize Premier League relevance and connect content back to fixtures, predictions, pundits and receipts.
