# Current Live-Site UI Audit

## What improved since the previous plan
The product hierarchy is closer to the intended model: Predict, Banter, Studio, Leagues and Season Calls now form a more coherent navigation model. The homepage explanation is shorter and Studio is more clearly acknowledged as part of the core journey.

## Current critical gaps

### 1. Studio is still visually smaller than its product importance
Studio should feel like a creator workspace. It must not open as a sparse information page or a generic prompt box. Its first screen should surface ready-to-create stories assembled from the user's predictions, followed pundits, match results, Aura/league movement and trending football context.

### 2. Homepage needs to prove the product immediately
The homepage should not rely on explanatory copy to communicate fun. Above and directly below the fold, show real feed cards: general football banter, GIF/meme cards, pundit receipts, community receipts, user-vs-pundit clashes, trending story cards and Studio-ready story cards.

### 3. Core football surfaces must never look dead
Matchweek/current fixtures and table/standings have previously resolved as structurally empty. Season Calls has exposed loading-only content. A data outage must produce a designed state with explanation, retry/freshness information and telemetry—not blank whitespace.

### 4. First-time users see too many zero-value metrics
Cards such as zero Aura, zero leagues and zero open picks can make the product look empty. Anonymous/first-time layouts should prioritize active public content and sample mechanics. Personal metrics should become prominent after the user has activity.

### 5. Pundit following is not prominent enough
Following pundits should appear during onboarding and in discovery. The product promise is strongest when a user understands: “I make my call, pundits make theirs, Ball Takes remembers both, reality settles it, Studio turns the receipt into content.”

### 6. GDPR/robot/consent surfaces must feel integrated
Keep separate terms/session acceptance and advertising consent. Consent should be concise, accessible and non-deceptive. Ad slots must collapse when consent is absent or inventory does not fill. Security/robot checks must not be bypassed by app code.

## Visual diagnosis
The site does not need more decorative effects. It needs more changing football context. Liveliness should come from:
- club crests and team identity
- fixture/result state
- pundit portraits/identity where legally/licensably appropriate
- prediction vs reality comparisons
- GIFs and memes
- receipts
- Aura/rank movement
- Studio transformations
- feed freshness
- restrained micro-motion

Principle: **The shell is clean. The football and banter are chaotic.**
