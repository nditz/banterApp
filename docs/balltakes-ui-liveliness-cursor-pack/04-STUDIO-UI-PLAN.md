# Studio UI Plan

## Studio is the core destination
Do not treat it as a generic text-generation page.

## Desktop layout
Use a creator-workspace layout:

Left rail:
- Story sources
- Recent receipts
- Pundit clashes
- Trending stories
- Saved creations

Center:
- selected story context
- content type
- tone
- generation controls
- generated output

Right rail (optional on wide screens):
- source facts
- related statistics
- pundit/user comparison
- copy/export actions

## Mobile
Use staged flow:
1. Select story
2. Select format
3. Select energy
4. Generate
5. Review/copy/export

## Story cards
Examples:
- You beat Gary Neville
- Your Manchester derby call aged terribly
- Your private league moved you #7 -> #1
- Pundit take aged badly
- Trending football story

## Content types
- Short video script
- Podcast segment
- Meme concept
- Instagram carousel outline
- X thread
- Caption

## Energy/tone
- Funny
- Ruthless
- Analytical
- Rant
- Victory lap
- Self roast
- Pundit-style

## Generated content pack
Must support:
- Hook
- Script
- Key facts
- Suggested visual plan
- AI media prompt
- Voiceover prompt
- Caption
- Hashtags
- source/context metadata

Actions:
- Copy script
- Copy AI prompt
- Copy full content pack
- Regenerate angle
- Save

## Do not
- start with blank prompt
- hide source context
- generate huge undifferentiated text blocks
- make export a secondary afterthought
