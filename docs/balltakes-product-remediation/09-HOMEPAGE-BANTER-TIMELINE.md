# Homepage & Banter Timeline

## Goal
Make the homepage entertaining even before login.

## Hero
Keep concise:
- value proposition;
- primary predict CTA;
- Studio CTA or visible Studio pathway.

Suggested direction:
"Football keeps the score. We keep the receipts."

Supporting line:
"Make your calls. Challenge the pundits. Turn the receipts into content."

## Timeline Content Mix
Mix visual card types:
- GIF reaction;
- meme;
- pundit receipt;
- user vs pundit;
- community exact-score hero;
- hot take;
- majority-wrong stat;
- match banter;
- trending football story.

## Timeline Rules
- content should rotate;
- avoid same GIF/template repeatedly;
- add recent-history exclusion;
- rank relevance/freshness;
- distinguish generic public content from personalized content;
- do not expose private user content without appropriate privacy settings.

## Logged-In Homepage
Prioritize:
- Aura;
- current matchweek progress;
- next fixtures;
- followed pundit takes;
- new receipts;
- league movement;
- Studio-ready stories.

## Empty State Rule
Never render a visually broken empty feed.
Use designed fallbacks or hide non-essential empty modules.
