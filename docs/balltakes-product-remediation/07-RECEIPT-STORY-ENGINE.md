# Receipt & Story Engine

## Receipt Definition
A receipt is a structured, persistent representation of a take and its outcome.

## Suggested Receipt Context
- user id (where applicable);
- pundit id(s);
- competition;
- fixture;
- user prediction;
- pundit prediction/take;
- final result;
- relevant stats;
- timestamp of take;
- settlement result;
- Aura impact;
- league movement;
- storyline type;
- source provenance;
- generated content references.

## Story Types
Examples:
- user beat pundit;
- pundit beat user;
- exact score;
- spectacular miss;
- majority was wrong;
- minority was right;
- friend rivalry;
- league rank swing;
- season prediction aging well/badly;
- pundit contradiction;
- comeback;
- upset;
- derby;
- title/relegation consequence.

## Story Engine Responsibilities
1. Identify meaningful events.
2. Rank them by novelty/relevance.
3. Avoid repetitive story archetypes.
4. Build structured context.
5. Generate safe banter angle options.
6. Make stories available to homepage/Banter/Studio.

## Novelty
Reuse the existing/randomization work where possible.
Avoid repeatedly producing the same GIF, meme template, hook or storyline.
