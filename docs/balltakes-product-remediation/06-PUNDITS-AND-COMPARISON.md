# Pundits & Comparison Engine

## Goal
Make user-vs-pundit comparison a first-class product feature.

## Pundit Model
Audit existing entities first. Extend only if necessary.

Suggested capabilities:
- pundit profile;
- source/platform;
- topics/teams;
- followed by user;
- prediction/take;
- source URL/reference;
- source timestamp;
- confidence/structured interpretation if used;
- provenance.

## Follow Experience
Users should be able to choose pundits they want to follow.

Following controls:
- whose predictions appear in comparison views;
- whose takes feed personalized Banter;
- whose history is available to Studio.

## Comparison
Before match:
- user pick;
- selected pundit picks;
- friends/league summary if available.

After match:
- actual result;
- who was right;
- exact result/outcome comparison;
- Aura impact;
- receipt candidate.

## Important Content Rule
When using real pundit quotes or content:
- preserve source attribution;
- store source references;
- do not fabricate direct quotations;
- generated summaries should be clearly differentiated from sourced quotes.
