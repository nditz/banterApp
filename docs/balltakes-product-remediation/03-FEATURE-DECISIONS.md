# Feature Decisions

## Core / Expand

### Fixtures & Matchweek
Core. Must be reliable and visible.

### Predictions
Core. Must support match and season calls.

### Pundits
Core differentiator. Users should be able to follow selected pundits and compare predictions/takes.

### Receipts
Core. Persistent structured record of what was said, what happened and who was right.

### Banter
Core. Public and personalized story layer.

### Studio
Central product destination. Must be expanded significantly.

### Leagues
Core retention/social loop.

### Aura
Keep as the primary user-facing scoring/reputation system.

## Keep but Reframe

### Awards
Rename/reframe as `Season Calls` or similar.
Use for:
- league winner;
- top scorer;
- top assists;
- goalkeeper;
- player of the season;
- other long-horizon predictions.

### Table
Keep as secondary/contextual data.
Do not treat a generic Premier League table as a core differentiator.
Where useful, contextualize it against predictions and Studio stories.

### History
Keep as `Receipts` / prediction history / content history.
This is valuable for end-of-season or retrospective content creation.

## Remove / Merge / Demote

### Studio as an empty prompt page
Replace with a story-driven workspace populated from user and football context.

### Generic standalone news
Only keep where it feeds story generation, trends or Studio context.

### RSS / YouTube as visible product features
Treat primarily as backend context sources unless UX value is proven.

### Long homepage quick tour
Reduce to a short explanation. Demonstrate product with actual content.

## Decision Rule
A page or feature earns primary navigation if it directly supports one or more of:
- create a prediction/take;
- compare with pundits;
- generate a receipt;
- create/share content;
- compete socially;
- retain the user.
