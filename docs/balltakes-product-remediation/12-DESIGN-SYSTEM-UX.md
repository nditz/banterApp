# Design System & UX Direction

## Design Direction
Premium football editorial product + Gen-Z banter + Ball Takes black/green brand.

## Core Principle
**The interface is clean. The banter is chaotic.**

## Visual Roles
- black/off-black: application shell;
- white/off-white: primary typography;
- Ball Takes green: CTA, selection, Aura, progress;
- club colors: contextual accents only;
- GIFs/memes: primary visual disruption.

## Rules
- no arbitrary new colors;
- avoid one-off Tailwind values when tokens exist;
- prefer whitespace over borders;
- minimize glassmorphism;
- avoid unnecessary gradients;
- avoid excessive green surfaces;
- avoid excessive rounded cards;
- use shared primitives;
- design loading, empty, error and disabled states;
- test mobile 375px, tablet ~768px, desktop ~1440px.

## Shared Primitives
Audit/reuse or create:
- Button
- Card
- Badge
- Avatar
- Tabs
- Modal
- Input
- Skeleton
- EmptyState
- ErrorState
- SectionHeader
- PageContainer
- MatchCard
- ReceiptCard
- PunditCard
- StoryCard
- AdSlot

## Homepage
Show actual product content early.
Reduce explanatory quick-tour content.

## Studio
Studio should visually feel like a creation workspace, not a generic admin form.
