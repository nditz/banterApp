# Studio - Central Feature

## Principle
Studio is not a blank AI prompt.
Studio is a context-rich football content workspace.

## Studio Inputs
Studio should surface selectable stories from:
- user predictions;
- user vs pundit;
- league rivalries;
- match results;
- Aura movement;
- exact scores;
- failed predictions;
- season calls;
- trending football events;
- pundit takes;
- news/RSS;
- YouTube/transcript context;
- historical receipts.

## Studio Home
Suggested sections:
- Your latest receipts
- You vs pundits
- Trending stories
- League drama
- Season storylines
- Previous projects

## Content Types
At minimum design for:
- Short/Reel/TikTok script
- Podcast segment
- Meme concept
- Caption
- X thread
- Instagram carousel
- Commentary

## Tone / Angle
Examples:
- Funny
- Ruthless
- Analytical
- Rage / rant
- Victory lap
- Self roast
- Pundit style
- Neutral explainer

## Content Pack Output
A Studio generation should return structured output such as:
- title;
- hook;
- script;
- facts/context;
- suggested visual plan;
- meme/GIF direction;
- caption;
- hashtags;
- AI image/video prompt;
- voiceover prompt;
- source notes where appropriate.

## Export
Initially prioritize:
- Copy Script
- Copy Prompt
- Copy Content Pack
- Download structured text/JSON if already supported or low-cost

Direct third-party integrations can be phased later.

## History
Save generated content packs so users can revisit and regenerate variants.

## Safety / Integrity
Never invent factual football data when structured data exists.
Generated output should distinguish sourced facts from generated creative framing.
