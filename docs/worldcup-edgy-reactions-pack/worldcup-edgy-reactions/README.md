# World Cup Edgy Reactions Pack

A drop-in content/config starter pack for a Next.js World Cup prediction game.

Use this with Cursor to add animated reaction cards, aura badges, banter copy and share receipts.

Start with:

```text
docs/CURSOR_IMPLEMENTATION_PROMPT.md
```

Then copy the `src` and `public` folders into your project and adapt imports to your app structure.

## Recommended approach

Your approach is good, but avoid putting slang directly into UI components. This pack keeps copy in config files so you can rotate it during the tournament.

## Dependencies

Optional:

```bash
npm install framer-motion
```

The SVG assets work without Framer Motion.
